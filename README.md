# Markdown Editor - 技術ブログ開発メモ

## 概要

Next.js で構築した自作技術ブログ。以下の機能を実装している。

- **Qiita・microCMS の記事一覧表示**：Qiita API および microCMS の公開 API を利用し、投稿記事の一覧を表示する
- **自作マークダウンエディタ**：microCMS は使わず独自実装。記事データは Firestore に保存する。現状は 1 記事を編集できる構成で、今後ブラッシュアップ予定

---

## 背景・方針

- 自作の技術ブログを Next.js で構築し、記事閲覧だけでなくエディタ機能も実装した
- Qiita および microCMS の記事一覧を同一画面で確認できるようにしている
- 自作エディタのコンテンツ管理にはFirestore を利用する
- 下書き機能は今回のスコープに含めない
- 機能を制限した分、セキュリティ（XSS 対策など）を重点的に強化する

## MVP ロードマップ

### MVP 1：画面の骨格を作る

- トップページにマイブログ見出しを作る
- マイブログ記事カードを 1 件表示する（内容はダミー）
- 記事参照画面・編集画面のルーティングを設定する

### MVP 2：編集機能を実装する

- マークダウンエディタを実装する（左：エディタ／右：プレビュー）
- タイトル編集フォームを実装する
- 公開ボタンを実装する（確認メッセージ → OK で Firestore に保存）

### MVP 3：Firestore 連携

- Firestore を利用して記事データを取得・保存する
- 記事一覧・記事参照画面で Firestore のデータを表示する
- 編集内容を Firestore に書き込む（サーバーサイドのみ）

### MVP 4：Qiita・microCMS 記事一覧表示

- Qiita API を利用して投稿記事の一覧を取得・表示する
- microCMS の記事一覧と合わせてトップページに表示する

### MVP 5：画像アップロード

- 画面キャプチャの貼り付けで、画像を Firebase Storage に保存・取得する（容量制限あり）

### ✅ 今回のスコープ

- トップページに Qiita・microCMS の記事一覧を表示する
- マイブログ記事カードをクリックすると詳細表示画面へ遷移
- マイブログ記事詳細表示画面構成
  - タイトル
  - 更新日
  - 本文
  - 編集ボタン（クリックするとマイブログ記事編集画面へ遷移）
- マイブログ記事編集画面構成
  - タイトル編集フォーム
  - マークダウンエディタ（画面左）
  - プレビュー（画面右）
  - 公開ボタン（確認メッセージ → OK で Firestore に保存）
- マークダウンエディタの実装（自作・現状は 1 記事編集、今後ブラッシュアップ予定）
- 記事内容を Firestore から取得・更新
- 記事内画像を Firebase Storage に保存（容量制限あり）
- 誰でも編集可能（認証なし）

> **注意**：下書き保存機能は今回のスコープ外。編集内容は公開ボタン押下時に直接 Firestore へ反映される。

### 残課題

- エディタのブラッシュアップ（複数記事の編集対応、画像挿入、undo / redo など）
- 下書き機能（Firestore への下書き保存）
- Firebase Auth で認証追加（投稿者のみ編集可能に）

## セキュリティ方針

機能をシンプルに絞った分、セキュリティを重点的に対応する。

- **ストレージ**：アップロード前にファイルサイズ・拡張子をバリデーション
- **Firestore**：書き込みはサーバーサイドのみで行い、クライアントから直接書き込ませない
- **microCMS API キー**：サーバーサイドのみで使用し、クライアントに露出させない

## データ設計

### Firestore（エディタデータ）

自作エディタで作成・編集する記事を管理する。

```
コレクション: myblogs
  └── ドキュメント: {id}
        ├── title: "記事タイトル"
        ├── content: "本文（Markdown）"
        ├── createdAt: timestamp
        └── updatedAt: timestamp
```

- 取得：サーバーサイドで Firestore SDK を使用
- 更新：Server Actions 経由でサーバーサイドのみ書き込み

### microCMS（記事一覧表示用）

トップページの記事一覧表示にのみ利用する。編集・書き込みは行わない。

- 取得：`GET /api/v1/myblogs`（公開 API）

### Qiita

- 取得：`GET https://qiita.com/api/v2/authenticated_user/items`（Qiita API v2）
- アクセストークンはサーバーサイドのみで使用し、クライアントに露出させない

### Firebase Storage

```
/image/{ファイル名}  # 記事内画像
```
